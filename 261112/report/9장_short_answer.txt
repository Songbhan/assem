9장 Strings and Arrays
9.9.1 Short Answer (1~14번) - 정답 및 풀이
기준: 교재 문제 사진과 9장 강의자료 (기본 32비트 MASM + Irvine32).


====================================================================
1번. 문자열 명령어 실행 시 인덱스 레지스터가 메모리의 낮은 주소로 이동하게 하는 DF 설정은?
[정답]
DF = 1 (STD).
[풀이]
STD는 DF를 1로 설정한다. CLD는 DF를 0으로 만들고 높은 주소 방향으로 이동하게 한다.

====================================================================
2번. 반복 접두사와 STOSW를 함께 사용하면 인덱스 레지스터에 더하거나 빼는 값은?
[정답]
2바이트.
[풀이]
STOSW는 AX를 [EDI]에 저장한다. DF=0이면 EDI+2, DF=1이면 EDI-2이다. REP에 의해 ECX는 매번 1씩 감소한다.

====================================================================
3번. CMPS 명령어가 어떤 점에서 모호한가?
[정답]
비교하는 두 메모리 피연산자의 순서가 명령어 이름만으로 명확하지 않다.
[풀이]
실제 연산은 [ESI] - [EDI] 기준으로 플래그를 설정한다. CMPSB/CMPSW/CMPSD는 비교 크기도 구분한다. 두 메모리 주소는 암묵적으로 정해져 있다.

====================================================================
4번. DF=0이고 SCASB가 일치하는 문자를 발견했을 때 EDI는 어디를 가리키는가?
[정답]
일치한 문자 바로 다음 바이트.
[풀이]
SCASB는 AL과 [EDI]를 비교한 후 EDI를 1 증가시킨다. 일치한 문자의 주소는 EDI-1이다.

====================================================================
5번. 배열에서 특정 문자가 처음 나타나는 곳을 찾을 때 적절한 반복 접두사는?
[정답]
REPNE (또는 REPNZ).
[풀이]
REPNE SCASB는 ECX가 0이 아니면 비교하고, 비교 결과 ZF=0인 동안 계속한다. ZF=1이면 찾은 것이다.

====================================================================
6번. 9.3절의 Str_trim 프로시저에서 DF는 어떻게 설정되는가?
[정답]
별도로 설정되지 않으며 값에 관계없이 동작한다.
[풀이]
강의자료 16쪽 코드는 MOV, CMP, DEC EDI, LOOP로 뒤에서 앞으로 검사한다. SCAS 등 문자열 기본 명령어를 쓰지 않으므로 DF는 영향을 주지 않는다.

====================================================================
7번. Str_trim에서 JNE 명령어를 사용하는 이유는?
[정답]
제거할 문자와 다른 문자가 나오면 반복을 멈추기 위해서.
[풀이]
CMP AL,char 후 JNE L2로 이동하면 마지막으로 남길 문자 바로 다음 위치에 NULL을 저장한다. 뒤에 연속된 지정 문자만 제거한다.

====================================================================
8번. Str_ucase의 대상 문자열에 숫자가 포함되면 어떻게 되는가?
[정답]
숫자는 변경되지 않는다.
[풀이]
ASCII 소문자 a~z 범위에 있을 때만 AND 11011111b를 적용한다. 숫자는 범위 검사에서 제외된다.

====================================================================
9번. Str_length에서 SCASB를 사용한다면 가장 적합한 반복 접두사는?
[정답]
REPNE (REPNZ).
[풀이]
AL=0으로 설정하고 NULL 문자를 찾을 때까지 SCASB를 반복한다.

====================================================================
10번. SCASB로 Str_length를 구현할 때 문자열 길이를 어떻게 계산해 반환하는가?
[정답]
cld
mov edi,pString
mov ecx,0FFFFFFFFh
xor eax,eax
repne scasb
not ecx
dec ecx
mov eax,ecx
[풀이]
ECX 초기값 - 최종값이 검사한 바이트 수(종료 NULL 포함)이다. 초기값이 FFFFFFFFh인 경우 NOT ECX로 검사 횟수를 구한 뒤 DEC로 NULL을 제외한다. 유효한 NULL 종료 문자열을 전제로 한다. EDI를 보존해야 하면 USES edi 등을 사용한다.

====================================================================
11번. 원소가 1,024개인 배열에서 교재의 이진 탐색이 필요로 하는 최대 비교 횟수는?
[정답]
11회 (중간 원소를 검사하는 횟수).
[풀이]
1024=2^10. 최악의 경우 범위가 1024→512→256→128→64→32→16→8→4→2→1로 줄어 마지막 원소까지 검사한다. 실제 CMP 명령 실행 횟수와는 다르다.

====================================================================
12번. Binary Search 예제의 FillArray에서 CLD로 DF를 0으로 만들어야 하는 이유는?
[정답]
STOSD가 배열의 앞에서 뒤로 이동하며 저장하도록 하기 위해서.
[풀이]
EDI를 배열 시작 주소로 설정한 경우 DF=1이면 첫 저장 뒤 EDI가 4 감소하여 배열 앞의 메모리를 침범할 수 있다.

====================================================================
13번. BinarySearch의 L2에 있는 문장을 제거해도 결과에 영향을 주지 않는 이유는?
[정답]
L2의 CMP EDX,EDI가 중복 비교이기 때문이다.
[풀이]
직전 CMP EDX,EDI 이후 JGE L2가 실행된다. JGE는 플래그를 변경하지 않으므로 L2에서는 직전 비교 결과를 그대로 JLE에 사용할 수 있다.

====================================================================
14번. BinarySearch에서 L4에 있는 문장을 어떻게 없앨 수 있는가?
[정답]
JMP L4를 JMP L1으로 변경한 뒤 L4: JMP L1을 제거한다.
[풀이]
강의자료 37쪽에서 L4는 반복문의 시작 L1으로 점프만 한다. first 또는 last를 갱신하는 두 경로에서 직접 L1으로 이동시키면 된다.
