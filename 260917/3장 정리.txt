1. 어셈블리 언어 기본 구조
- CPU 레지스터, 플래그 등에 직접 접근 가능
- 주요 영역: .data, .code, .stack
- main PROC: main 프로시저 시작
- main ENDP: main 프로시저 종료
- INVOKE ExitProcess, 0: 프로그램 종료 후 운영체제로 제어 반환

2. 정수 리터럴(Integer Literal)
- 형식: [+ 또는 -] 숫자 [radix]
- h = 16진수
- q/o = 8진수
- d/t = 10진수
- b/y = 2진수
- 예: 26d, 11010011b, 42q, 1Ah

3. 상수 정수식(Constant Integer Expression)
- 정수 리터럴과 산술 연산자로 구성
- 우선순위:
  () → 단항 +,- → *, /, MOD → +,-
- 예: 4 + 5 * 2 → 곱셈 먼저 수행

4. 실수 / 문자 / 문자열
- 실수: 부호, 정수부, 소수부, 지수부 사용 가능
- 문자 리터럴: 'A', "d"처럼 문자 1개
- 문자열: 'ABC', "Good night"처럼 여러 문자
- 작은따옴표 또는 큰따옴표 사용 가능

5. 예약어(Reserved Words)
- 명령어: MOV, ADD, MUL 등
- 레지스터 이름
- 지시어(Directive)
- 연산자
- 미리 정의된 심볼
- 예약어와 같은 이름을 식별자로 사용할 수 없음

6. 식별자(Identifier)
- 길이: 1~247자
- 대소문자 구분하지 않음
- 첫 문자는 문자, _, @, ?, $ 가능
- 이후에는 숫자도 가능
- 예약어 사용 불가

7. Directive / Segment
- Directive: 어셈블러에게 처리 방법을 알려주는 명령
- .data: 변수/데이터 정의 영역
- .code: 실행 명령어 영역
- .stack: 런타임 스택 영역

8. Instruction 기본 형식
- [label:] mnemonic [operands] [;comment]
- Label: 선택
- Mnemonic: 필수
- Operand: 일반적으로 필요
- Comment: 선택
- 어셈블러가 기계어 바이트로 변환

9. Label
- 명령어나 데이터의 위치를 표시하는 식별자
- Data label / Code label 존재

10. Mnemonic
- MOV: 값 이동
- ADD: 덧셈
- SUB: 뺄셈
- MUL: 곱셈
- JMP: 다른 위치로 이동
- CALL: 프로시저 호출

11. Operand
- 명령어의 입력 또는 출력값
- 종류: 정수 리터럴, 정수식, 레지스터, 메모리
- 일반적으로 destination, source 순서
- 예: mov count, ebx → EBX 값을 count로 이동
- 명령어에 따라 피연산자 0~3개 사용 가능

12. 주석(Comment)
- ; 이후 같은 줄 내용은 어셈블러가 무시
- COMMENT 지시어로 여러 줄 주석 가능
- 프로그램 목적, 작성자, 수정일, 구현 설명 등에 사용

13. NOP
- No Operation
- 실제 작업 없음
- 1바이트 차지
- 코드 주소 정렬 등에 사용

14. 정수 덧셈 프로그램
- mov eax, 5 → EAX에 5 저장
- add eax, 6 → EAX에 6 더함
- 결과: EAX = 11
- .386: 프로그램이 요구하는 최소 CPU 지정
- .model flat, stdcall: protected mode용 flat 메모리 모델 및 Windows 함수 호출 방식 지정
- INVOKE: 프로시저/함수 호출

15. Assemble → Link → Run
- Source File → Assembler → Object File → Linker → Executable File → OS Loader → 실행
- .asm 소스 작성 → 어셈블 → .obj 생성 → 링크 → .exe 생성 → OS가 실행
- Listing File(.lst), Map File(.map) 생성 가능

16. 데이터 정의
- 데이터 정의문: 변수용 메모리 공간 확보
- BYTE / SBYTE = 8bit
- WORD / SWORD = 16bit
- DWORD / SDWORD = 32bit
- FWORD = 48bit
- QWORD = 64bit
- TBYTE = 80bit
- REAL4 = 32bit 실수
- REAL8 = 64bit 실수
- REAL10 = 80bit 실수
- ? = 초기화하지 않음

17. 배열과 문자열
- list BYTE 10,20,30,40
- 데이터는 메모리에 연속 저장
- list는 첫 번째 데이터의 주소를 가리킴
- greeting BYTE "Good afternoon",0
- 끝의 0은 null-terminated string을 의미

18. DUP 연산자
- 같은 형식의 저장 공간을 여러 개 생성
- BYTE 20 DUP(0) → 0으로 초기화된 20바이트
- BYTE 20 DUP(?) → 초기화되지 않은 20바이트
- array WORD 5 DUP(?) → 초기화되지 않은 16비트 값 5개

19. DWORD / SDWORD
- DWORD: 32비트 unsigned 정수
- SDWORD: 32비트 signed 정수

20. 실수 자료형
- REAL4: 4바이트 단정도
- REAL8: 8바이트 배정도
- REAL10: 10바이트 확장 정밀도

21. Little-Endian
- x86은 Little-Endian 방식 사용
- 낮은 바이트를 낮은 주소에 저장
- 예: 12345678h → 메모리에는 78 → 56 → 34 → 12 순서

22. .DATA?
- 초기화되지 않은 데이터를 정의하는 영역
- 큰 배열처럼 초기값이 필요 없는 데이터를 선언할 때 프로그램 크기를 줄이는 데 유리

23. Symbolic Constants
- = 지시어: 심볼 이름과 정수 표현식 연결
- 예: COUNT = 500
- 값 재정의 가능
- $ = 현재 위치 카운터(Current Location Counter)
- 배열 크기 계산:
  BYTE 배열: ListSize = ($ - list)
  WORD 배열: ListSize = ($ - list) / 2
  DWORD 배열: ListSize = ($ - list) / 4

24. EQU
- 심볼 이름을 정수식 또는 임의의 텍스트와 연결
- 예:
  PI EQU <3.1416>
  matrix1 EQU 10 * 10

25. TEXTEQU
- 텍스트 매크로 정의
- 예: move TEXTEQU <mov>
- 이후 move 사용 시 mov로 치환
