Flag Register / Segment Register 요점 정리

1.  Flag Register

CPU의 연산 결과와 현재 상태를 저장하는 레지스터

-   ZF (Zero Flag): 연산 결과가 0일 때 설정
-   CF (Carry Flag): 자리올림 또는 빌림이 발생했을 때 설정
-   SF (Sign Flag): 연산 결과가 음수일 때 설정
-   OF (Overflow Flag): 연산 결과가 표현 가능한 범위를 넘었을 때 설정
-   조건부 점프 등의 명령에서 플래그 값을 이용

요약: 연산 결과의 상태를 나타내는 레지스터

2.  Segment Register

메모리의 특정 영역을 참조하기 위해 사용하는 레지스터

-   CS (Code Segment): 실행 코드 영역
-   DS (Data Segment): 데이터 영역
-   SS (Stack Segment): 스택 영역
-   ES, FS, GS: 추가적인 메모리 영역 참조

요약: 메모리의 어느 영역을 사용할지 참조하는 레지스터

3.  차이점

Flag Register - CPU의 연산 결과와 상태를 나타냄 - 대표적으로 ZF, CF, SF,
OF 등이 있음

Segment Register - 메모리 영역을 참조할 때 사용 - 대표적으로 CS, DS, SS,
ES, FS, GS가 있음

핵심 정리

Flag Register = 연산 상태 Segment Register = 메모리 영역
