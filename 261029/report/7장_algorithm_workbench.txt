======================================================================
1번
CWD 없이 AX의 부호 비트를 EAX의 상위 16비트까지 복사하라.

[정답]
shl eax,16
sar eax,16

[풀이]
AX를 상위 16비트로 옮기고, SAR로 오른쪽 16비트 이동하며 부호를 채운다.
AX 음수면 상위가 FFFFh, 양수면 0000h가 된다.

======================================================================
2번
회전 명령 없이 SHR과 조건 점프로 AL을 오른쪽 1비트 회전시키라.

[정답]
shr al,1
jnc Done
or al,80h
Done:

[풀이]
SHR에서 빠진 최하위 비트가 CF에 남는다.
CF=1이면 원래 비트 0을 비트 7에 되돌려 회전 효과를 만든다.

3번
EAX를 16배 하는 논리적 시프트 한 줄을 작성하라.

[정답]
shl eax,4

[풀이]
왼쪽 4비트 이동 = 2^4배. 상위 비트가 잘리면 일반 정수 곱셈과 달라질 수 있다.

[풀이]
오른쪽 2비트 이동 = 부호 없는 수를 4로 나눈 몫.

5번
DL의 상위 4비트와 하위 4비트를 한 명령어로 교환하라.

[풀이]

6번
AX 최상위 비트를 DX 최하위 비트에 넣으며 DX를 왼쪽 1비트 이동시키라.

[정답]
shld dx,ax,1

[풀이]
DX를 한 칸 왼쪽으로 밀고 비트 0 자리에 AX의 비트 15를 채운다.
AX는 변하지 않는다.

7번
아래 3바이트를 하나의 연속된 24비트 수처럼 오른쪽 1비트 이동시키라.
byteArray BYTE 81h,20h,33h

[정답]
shr BYTE PTR [byteArray+2],1
rcr BYTE PTR [byteArray+1],1
rcr BYTE PTR [byteArray],1

실행 후: 40h,90h,19h.

[풀이]
높은 바이트부터 오른쪽으로 이동하고, CF를 다음 바이트의 비트 7로 전달.
원래 332081h → 오른쪽 이동 → 199040h (리틀 엔디언 순서로 40 90 19).

8번
아래 3개 WORD를 연속된 48비트 수처럼 왼쪽 1비트 이동시키라.
wordArray WORD 810Dh,0C64h,93ABh

[정답]
shl WORD PTR [wordArray],1
rcl WORD PTR [wordArray+2],1
rcl WORD PTR [wordArray+4],1

실행 후: 021Ah,18C9h,2756h.

[풀이]
낮은 WORD부터 왼쪽으로 이동하고 CF를 다음 WORD의 비트 0에 전달.
48비트의 맨 위를 넘어가는 비트는 CF에 남는다.

9번
정수 -5를 3으로 나눈 몫을 16비트 변수 val1에 저장하라.

[정답]
mov ax,-5
cwd
mov bx,3
idiv bx
mov val1,ax

결과: val1=-1, 나머지 DX=-2.

[풀이]
IDIV는 부호 있는 나눗셈. CWD로 AX의 부호를 DX까지 확장해야 한다.
몫은 0 방향으로 버리므로 -5 / 3 = -1, 나머지 -2.

11번
32비트 unsigned 식을 구현하라.
val1 = (val2 * val3) / (val4 - 3)

[정답]
mov ebx,val4
sub ebx,3           ; 나눌 수
jz DivideError      ; 0 나누기 방지
mov eax,val2
mul val3            ; EDX:EAX = val2 * val3
div ebx             ; EAX = 몫
mov val1,eax
jmp Done
DivideError:
    ; 오류 처리
Done:

[풀이]
MUL로 나온 64비트 곱은 EDX:EAX에 담기므로 그대로 DIV에 사용.
이 예시는 0 나누기는 막지만, 몫이 EAX에 안 들어가면 DIV 예외가 날 수 있다.

12번
32비트 signed 식을 구현하라.
val1 = (val2 / val3) * (val1 + val2)

[정답]
mov ebx,val1
add ebx,val2           ; 오른쪽 괄호 저장
mov eax,val2
cdq                    ; signed 64비트 피제수
cmp val3,0
je DivideError
idiv val3              ; EAX = val2 / val3
imul eax,ebx           ; EAX = 몫 * (원래 val1+val2)
mov val1,eax
jmp Done
DivideError:
    ; 오류 처리
Done:

[풀이]
IDIV 전에 CDQ로 EAX 부호를 EDX까지 확장한다.
두 피연산자 IMUL은 32비트 결과만 보관하므로 OF를 확인하면 좋다.
주의: -2147483648 / -1처럼 0이 아닌 제수에서도 몫 오버플로가 발생할 수 있다.

13번
AL로 받은 0~99의 8비트 정수를 십진수 문자로 출력하는 프로시저를 작성하라.
Irvine32의 라이브러리 중 WriteChar만 사용한다.

[정답]
WriteDecimal8 PROC
    aam                    ; AH=십의 자리, AL=일의 자리
    add ax,3030h           ; 둘 다 ASCII 코드로 변환
    push eax
    mov al,ah
    call WriteChar          ; 십의 자리
    pop eax
    call WriteChar          ; 일의 자리
    ret
WriteDecimal8 ENDP

호출 예: mov al,65 / call WriteDecimal8  → 65 출력.

[풀이]
AAM은 AL을 십진 두 자리로 분리한다(기수 10).
이 코드는 0~9도 00~09처럼 2자리로 출력한다.
AAM은 레거시 32비트 명령이며 x86-64 모드에서는 사용할 수 없다.

14번 (Challenge)
AX=0072h이고 AF=1일 때 AAA 명령을 실행하면 결과는?

[정답]
AX = 0108h (AH=01h, AL=08h), AF=1, CF=1.

[풀이]
AL 하위 4비트=2이지만 AF=1이므로 보정 발생.
AL에 6을 더하고 AH를 1 증가시킨 뒤 AL 상위 4비트를 0으로 만든다.
72h+6=78h → AL=08h, AH=01h. (64비트 모드에서는 AAA 사용 불가.)

15번 (Challenge)
SUB, MOV, AND만으로 x = n mod y를 계산하라.
n은 unsigned, y는 2의 거듭제곱이라고 가정.

[정답]
mov eax,y
sub eax,1
mov ebx,n
and ebx,eax
mov x,ebx

[풀이]
y가 2^k이면 나머지는 n의 하위 k비트와 동일.
따라서 n AND (y-1)로 계산 가능. 예: n=29, y=8 → 29 AND 7 = 5.

16번 (Challenge)
SAR, ADD, XOR만 이용하고 조건 점프 없이 EAX에 있는 signed 정수의 절댓값을 계산하라.

[정답]
xor edx,edx
add edx,eax
sar edx,31             ; 양수/0 → 0, 음수 → FFFFFFFFh
xor eax,edx            ; 음수면 비트 반전
xor edx,0FFFFFFFFh
add edx,1              ; edx = -원래 부호 마스크
add eax,edx            ; 음수이면 +1, 아니면 +0

[풀이]
음수는 NOT(비트 반전)+1이 2의 보수 절댓값이다.
주어진 세 명령어로 부호 마스크를 만들고 분기 없이 변환한다.
단, EAX=80000000h(최솟값 -2147483648)의 양수 절댓값은 signed 32비트에
표현할 수 없어 비트 패턴이 그대로 남는다.
