1. 스택(Stack)  [2~11쪽]
- LIFO: 마지막에 넣은 데이터가 먼저 나옴.
- ESP: 스택 맨 위의 주소를 가리킴.
- 32비트 PUSH: ESP -= 4 → 값 저장
- 32비트 POP : 값 꺼냄 → ESP += 4
- 스택은 낮은 주소 방향으로 쌓임.
- 사용 목적: 복귀 주소 저장, 레지스터 보존, 매개변수·지역변수 저장.

주요 명령어
  PUSH / POP     : 스택에 저장 / 스택에서 꺼내기
  PUSHFD / POPFD : EFLAGS 저장 / 복원
  PUSHAD / POPAD : 32비트 범용 레지스터 8개 저장 / 복원

주의: POP은 PUSH의 역순으로 해야 함.
      PUSHAD 후 POPAD를 하면 EAX의 계산 결과도 이전 값으로 돌아갈 수 있음.

2. 프로시저(Procedure)  [13~18쪽]
- 기능별로 코드를 묶은 것. 함수와 비슷함.
- PROC / ENDP: 프로시저 시작 / 끝
- CALL: 복귀 주소를 스택에 넣고 프로시저로 이동
- RET : 스택의 복귀 주소를 꺼내 원래 위치로 돌아감
- JMP : 이동만 함. CALL과 달리 복귀 주소를 자동 저장하지 않음.

흐름: main → CALL → 프로시저 실행 → RET → main의 다음 명령어
중첩 호출: main → Sub1 → Sub2 / 복귀: Sub2 → Sub1 → main

값 전달 및 반환
- EAX, EBX, ECX, ESI 등 레지스터로 값을 전달할 수 있음.
- 수업 예제에서는 계산 결과를 주로 EAX로 반환함.
- 다른 곳에서 쓰던 레지스터는 PUSH로 보관하고 POP으로 복원.
- USES esi ecx: 해당 레지스터의 PUSH/POP을 자동 생성.
  (반환값인 EAX까지 보존하면 결과가 사라질 수 있으니 주의)

3. ArraySum 예제  [19~23쪽]
목적: DWORD 배열의 값을 모두 더하기
  ESI = 배열 시작 주소
  ECX = 배열 원소 개수
  EAX = 합계(반환값)

ArraySum PROC USES esi ecx
    mov eax,0
L1:
    add eax,[esi]        ; 현재 원소 누적
    add esi,TYPE DWORD   ; 다음 원소로 이동(+4바이트)
    loop L1              ; ECX--, 0이 아니면 반복
    ret
ArraySum ENDP

기억할 것
- OFFSET array : 배열 시작 주소
- LENGTHOF array : 원소 개수
- TYPE DWORD : 원소 하나의 크기 = 4바이트
- [esi] : ESI에 들어 있는 주소가 가리키는 메모리 값
- 배열이 WORD이면 다음 원소 이동 크기는 2바이트.

수업 예제 배열: 10000h, 20000h, 30000h, 40000h, 50000h
합계: EAX = 000F0000h

4. 외부 라이브러리 연결  [25~26쪽]
- .obj : 어셈블한 목적 파일
- .lib : 다른 프로시저를 연결할 때 쓰는 라이브러리
- .dll : 실행 중 사용하는 동적 연결 라이브러리
- 예: Irvine32.lib, kernel32.lib, kernel32.dll

5. Irvine32 라이브러리  [27~41쪽]
콘솔 입출력과 화면 제어 기능을 쉽게 사용하는 라이브러리.

함수              기능 / 주요 레지스터
--------------------------------------------------
Clrscr            화면 지우기
Crlf              줄 바꾸기
WriteString       문자열 출력 / EDX=문자열 주소
ReadString        문자열 입력 / EDX=버퍼 주소, ECX=최대 길이
ReadInt           부호 있는 정수 입력 / 결과 EAX
WriteInt          부호 있는 정수 출력 / EAX
WriteDec          부호 없는 정수 출력 / EAX
WriteHex          16진수 출력 / EAX
WriteBin          2진수 출력 / EAX
WriteChar         문자 1개 출력 / AL
DumpRegs          레지스터와 플래그 확인
DumpMem           메모리 내용 확인
Delay             지정한 시간만큼 대기 / EAX=밀리초
RandomRange       0~EAX-1 사이 난수 / 결과 EAX
SetTextColor      글자색·배경색 설정 / EAX
Gotoxy            커서를 지정 위치로 이동
--------------------------------------------------

간단한 사용 예
  mov edx,OFFSET str1
  call WriteString       ; 문자열 출력

  mov eax,100
  call RandomRange       ; 0~99 중 한 값

  mov eax,yellow + (blue * 16)
  call SetTextColor      ; 노란 글씨, 파란 배경
