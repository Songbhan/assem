5.8.2 Algorithm Workbench


1번
PUSH와 POP 명령어만 사용하여 EAX와 EBX 레지스터의 값을
서로 교환하는 명령어들을 작성하라.
(64비트 모드라면 RAX와 RBX를 사용한다.)

[정답]
push eax
push ebx
pop eax
pop ebx

[풀이]
스택은 나중에 넣은 값을 먼저 꺼내는 LIFO 구조이다.

처음:
EAX = A
EBX = B

1) push eax : 스택에 A 저장
2) push ebx : 스택에 B 저장 (B가 맨 위)
3) pop eax  : 맨 위의 B가 EAX에 들어감
4) pop ebx  : 그다음 A가 EBX에 들어감

최종:
EAX = B
EBX = A

[전체 예제 코드]
INCLUDE Irvine32.inc

.code
main PROC
    mov eax,10h
    mov ebx,20h

    push eax
    push ebx
    pop eax
    pop ebx

    ; 결과: EAX = 20h, EBX = 10h
    exit
main ENDP
END main


2번
서브루틴이 스택에 저장된 원래 복귀 주소보다
메모리 주소가 3바이트 높은 곳으로 복귀하도록 하려고 한다.
서브루틴의 RET 바로 앞에 넣을 명령어를 작성하라.

[정답]
add DWORD PTR [esp],3
ret

[풀이]
32비트 near CALL 직후, 서브루틴에 진입했을 때:
[ESP] = 원래 복귀 주소 (4바이트)

add DWORD PTR [esp],3
-> 스택에 들어 있는 '복귀 주소의 값'에 3을 더한다.

ret
-> 수정된 복귀 주소를 EIP로 가져와 그 주소로 이동한다.

즉, 기존 복귀 주소가 X였다면 X+3으로 복귀한다.
ESP에 3을 더하는 것이 아니라 [ESP]에 저장된 주소값을 3 증가시켜야 한다.
또한 '3바이트'이지 '명령어 3개'가 아님에 주의한다.

[전체 예제 코드]
INCLUDE Irvine32.inc

.code
main PROC
    call ReturnPlus3
    nop                       ; 1바이트
    nop                       ; 1바이트
    nop                       ; 1바이트
Here:
    mov eax,1234h
    ; 복귀하면 위 3개의 NOP를 건너뛰어 EAX = 1234h가 된다.
    exit
main ENDP

ReturnPlus3 PROC
    add DWORD PTR [esp],3
    ret
ReturnPlus3 ENDP
END main

주의:
복귀 주소 뒤의 3바이트가 위 예시의 NOP처럼 정확히 건너뛸 수 있는
부분이 아니라면, 다른 명령어 중간으로 진입하여 오류가 날 수 있다.


3번
서브루틴에서 DWORD(4바이트) 정수형 지역변수 2개를 위한
스택 공간을 확보하는 명령어를 작성하라.
그다음 두 지역변수에 각각 1000h와 2000h를 저장하라.

[정답]
sub esp,8
mov DWORD PTR [esp],1000h
mov DWORD PTR [esp+4],2000h

; 서브루틴에서 반환하기 전:
add esp,8
ret

[풀이]
DWORD 1개 = 4바이트
DWORD 2개 = 8바이트

sub esp,8
-> ESP를 8 감소시켜 지역변수 2개를 위한 공간을 확보한다.

mov DWORD PTR [esp],1000h
-> 새로 확보한 공간의 첫 DWORD에 1000h 저장

mov DWORD PTR [esp+4],2000h
-> 그다음 DWORD에 2000h 저장

스택 구조 (낮은 주소에서 높은 주소 순):
[ESP]   = 1000h   ; 지역변수 1
[ESP+4] = 2000h   ; 지역변수 2
[ESP+8] = 복귀 주소

서브루틴을 끝낼 때는 add esp,8로 스택 공간을 해제해야
RET이 올바른 복귀 주소를 읽을 수 있다.

[전체 예제 코드]
INCLUDE Irvine32.inc

.code
main PROC
    call LocalVars
    ; 실행 후 EAX = 3000h (검증을 위해 두 값을 더한 결과)
    exit
main ENDP

LocalVars PROC
    sub esp,8
    mov DWORD PTR [esp],1000h
    mov DWORD PTR [esp+4],2000h

    mov eax,[esp]
    add eax,[esp+4]

    add esp,8
    ret
LocalVars ENDP
END main


4번
인덱스 주소지정(indexed addressing)을 사용하여
DWORD 배열의 한 원소를 같은 배열의 바로 이전 위치로
복사하는 명령어들을 작성하라.

[정답]
; 예: array[2]의 값을 array[1]로 복사
mov esi,8
mov eax,array[esi]
mov array[esi-4],eax

[풀이]
DWORD 배열에서는 원소 하나의 크기가 4바이트이다.
따라서 바로 이전 원소는 주소상으로 4바이트 앞에 있다.

예:
array DWORD 10,20,30,40

바이트 오프셋:
array+0  -> array[0] = 10
array+4  -> array[1] = 20
array+8  -> array[2] = 30
array+12 -> array[3] = 40

mov esi,8
-> 세 번째 원소의 바이트 오프셋을 ESI에 저장

mov eax,array[esi]
-> 세 번째 원소(30)를 EAX로 읽음

mov array[esi-4],eax
-> 한 DWORD 앞인 두 번째 원소 자리에 30을 저장

최종 배열 (10진수):
10, 30, 30, 40

첫 번째 원소에는 이전 원소가 없으므로
이 방식에서 복사할 원소는 두 번째 이후여야 한다.

[전체 예제 코드]
INCLUDE Irvine32.inc

.data
array DWORD 10,20,30,40

.code
main PROC
    mov esi,8
    mov eax,array[esi]
    mov array[esi-4],eax

    ; 결과: array DWORD 10,30,30,40
    exit
main ENDP
END main


5번
서브루틴의 복귀 주소를 화면에 출력하는 명령어들을 작성하라.
스택을 수정하더라도 호출한 곳으로 정상 복귀할 수 있어야 한다.

[정답]
; Irvine32의 WriteHex를 사용한 32비트 예시
push eax
mov eax,[esp+4]
call WriteHex
pop eax
ret

[풀이]
서브루틴에 진입한 직후:
[ESP] = 복귀 주소

1) push eax
   EAX 원래 값을 스택에 보관한다.
   ESP가 4 감소했으므로, 복귀 주소는 이제 [ESP+4]에 있다.

2) mov eax,[esp+4]
   복귀 주소를 EAX에 복사한다.
   원래 복귀 주소는 스택에 그대로 남아 있다.

3) call WriteHex
   EAX의 32비트 값을 16진수로 출력한다.
   WriteHex가 정상 반환하면 호출 전의 ESP 위치로 돌아온다.

4) pop eax
   보관했던 원래 EAX 값을 복원한다.
   이제 스택 맨 위에는 원래 복귀 주소가 있다.

5) ret
   원래 복귀 주소로 정상 복귀한다.

중요:
복귀 주소를 POP으로 빼낸 상태에서 다른 함수를 호출하면
스택에 새로운 복귀 주소가 쌓여 혼란을 일으킬 수 있다.
위처럼 복귀 주소를 '복사'해 출력하면 더 안전하다.

[전체 예제 코드]
INCLUDE Irvine32.inc

.code
main PROC
    call ShowReturnAddress
    call Crlf
    exit
main ENDP

ShowReturnAddress PROC
    push eax
    mov eax,[esp+4]
    call WriteHex
    pop eax
    ret
ShowReturnAddress ENDP
END main

출력되는 16진수 주소값은 프로그램이 메모리에 배치되는 방식에 따라
달라질 수 있으므로 특정한 숫자로 고정할 수 없다.
위 예제에서 출력되는 주소는 main의 'call Crlf' 명령어 위치이다.
