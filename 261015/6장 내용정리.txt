6장 내용 정리



1. 조건 처리 기본  - 어셈블리에서 조건문은 비교/논리 연산으로 플래그를 바꾼 뒤 조건 점프로 구현.
- 기본 흐름: CMP 또는 TEST → 플래그 확인 → 조건이 맞으면 점프
- JMP는 조건 없이 이동, Jcc(JZ, JG 등)는 조건이 맞을 때만 이동.

2. 논리 연산과 비교 
명령어      기능                     주의할 점
--------------------------------------------------------------
AND         비트별 AND                특정 비트를 0으로 만드는 데 사용
OR          비트별 OR                 특정 비트를 1로 만드는 데 사용
XOR         비트별 배타적 OR          서로 다른 비트는 1, 같은 비트는 0
NOT         모든 비트 반전            플래그 변경 없음
TEST        AND 결과로 플래그만 확인   원래 피연산자 값은 변경 안 함
CMP         두 값의 차이로 플래그 확인  실제 값은 변경 안 함
--------------------------------------------------------------
- AND/OR/XOR/TEST: CF=0, OF=0으로 만들고 ZF/SF/PF를 결과에 맞게 설정.
- NOT: 플래그를 변경하지 않음.
- CMP: 목적지 - 원본을 계산한 것처럼 플래그를 설정하지만 값을 저장하지 않음.

자주 쓰는 플래그
  ZF=1 : 연산 결과가 0
  CF=1 : 부호 없는 뺄셈에서 빌림 발생 등
  SF=1 : 결과 최상위 비트가 1
  OF=1 : 부호 있는 연산에서 오버플로 발생
  PF=1 : 결과 하위 8비트의 1 개수가 짝수

간단한 예
  mov al,00001111b
  and al,00000101b    ; AL = 00000101b

  test al,00000001b   ; AL은 그대로, 비트 0이 켜졌는지 플래그로 판단

  cmp eax,10          ; EAX와 10을 비교 (EAX는 그대로)
  je SAME             ; 같으면 SAME으로 이동

- 비트마스크: AND는 선택한 비트 제거, OR는 선택한 비트 켜기.
- 집합 표현: AND = 교집합, OR = 합집합, NOT = 여집합.
- XOR를 같은 값으로 두 번 실행하면 원래 값으로 돌아옴(암호화 예제).

3. 조건 점프(Conditional Jumps)  

기본/플래그 점프
  JE / JZ    : 같음 / ZF=1
  JNE / JNZ  : 다름 / ZF=0
  JC / JNC   : CF=1 / CF=0
  JO / JNO   : OF=1 / OF=0
  JS / JNS   : SF=1 / SF=0
  JP / JNP   : PF=1 / PF=0

부호 없는 수(unsigned) 비교
  JA   : >
  JAE  : >=
  JB   : <
  JBE  : <=

부호 있는 수(signed) 비교
  JG   : >
  JGE  : >=
  JL   : <
  JLE  : <=

중요: 음수를 비교할 때는 signed용 JG/JL 계열을 사용.
      JA/JB 계열은 unsigned 비교용이므로 결과가 달라질 수 있음.

예
  mov eax,5
  cmp eax,10
  jl SMALL            ; signed 기준 5 < 10 → 점프함

- CMP 왼쪽 피연산자가 오른쪽보다 큰지/작은지 판단.
- JE와 JNE는 값의 일치 여부 비교에서 signed/unsigned 구분이 없음.
- JECXZ: ECX가 0이면 점프. LOOP와 달리 ECX를 감소시키지 않음.

4. 조건 반복 명령어  
- LOOP : ECX를 1 감소, ECX≠0이면 반복
- LOOPZ / LOOPE  : ECX≠0이고 ZF=1이면 반복
- LOOPNZ / LOOPNE: ECX≠0이고 ZF=0이면 반복
- 주의: LOOPZ/LOOPNZ 사이에 ADD 같은 플래그 변경 명령이 있으면
        비교 결과가 바뀔 수 있어 PUSHFD/POPFD로 플래그를 보존하기도 함.

5. IF / ELSE / WHILE 구조  
- IF   : CMP 후 조건이 거짓이면 해당 코드 건너뛰기
- ELSE : 한쪽 실행 후 JMP로 다른 쪽 건너뛰기
- AND 조건: 두 조건이 모두 참이어야 실행
- OR 조건 : 한 조건만 참이어도 실행
- WHILE: 비교 → 조건 거짓이면 종료 → 본문 실행 → 처음으로 이동

대표 예제
- ArrayScan: 배열을 순회하며 첫 번째 0이 아닌 값 찾기.
- Encrypt: 문자열 각 바이트에 XOR 키를 적용해 암호화/복호화.
- Table-driven selection: 값과 프로시저 주소를 표로 만들고
  일치하는 항목의 프로시저를 간접 CALL.

6. MASM 조건 제어 지시어 
- 32비트 MASM에서 고급 조건문을 간단히 작성하는 기능.
- 강의자료 기준 64비트 모드에서는 이 지시어를 사용할 수 없음.

  .IF 조건       : 조건문 시작
  .ELSEIF 조건   : 다른 조건 검사
  .ELSE          : 그 외 경우
  .ENDIF         : 조건문 끝
  .WHILE 조건    : 조건이 참인 동안 반복
  .ENDW          : WHILE 끝
  .REPEAT        : 먼저 본문 실행
  .UNTIL 조건    : 조건이 참이 되면 반복 종료
  .BREAK         : 반복문 종료
  .CONTINUE      : 다음 반복으로 이동

간단한 예
  mov eax,0
  .WHILE eax < 10
      inc eax
  .ENDW

- .WHILE은 시작 전에 조건 확인, .REPEAT는 본문을 먼저 실행.
- 이런 지시어도 어셈블 과정에서 비교 및 점프 코드로 변환됨.
