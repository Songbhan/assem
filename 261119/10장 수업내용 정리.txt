10장 Structures and Macros

1. STRUCT / ENDS
- STRUCT는 관련된 필드를 묶는 사용자 정의 자료형이다.
- 실제 변수는 구조체 이름으로 선언한다.

COORD STRUCT
    X WORD ?
    Y WORD ?
COORD ENDS

pos COORD <10,20>
mov ax,pos.X

- <> : 구조체 정의에 적힌 기본값 사용
- <10,20> : 선언 순서대로 필드 초기화
- TYPE / SIZEOF : 구조체 한 개의 크기(바이트)
- LENGTHOF : 구조체 배열 원소 개수

2. 구조체 주소와 정렬
- structVar.Field : 구조체 필드 접근
- OFFSET structVar.Field : 특정 필드 주소
- (COORD PTR [esi]).X : ESI가 가리키는 구조체의 X 접근
- 배열 다음 원소로 이동할 때 TYPE 구조체만큼 더함
- ALIGN WORD / ALIGN DWORD : 주소 정렬. 필요하면 패딩이 생김.

3. 중첩 구조체와 UNION
- 구조체 안에 다른 구조체를 필드로 둘 수 있다.
- UNION은 모든 필드가 같은 메모리 시작 위치를 공유한다.
- STRUCT는 각 필드가 별도 영역, UNION은 가장 큰 필드 크기만큼 공간 차지.

Integer UNION
    D DWORD ?
    W WORD ?
    B BYTE ?
Integer ENDS

4. 매크로 MACRO / ENDM
- 프로시저는 CALL로 호출하지만, 매크로는 어셈블할 때 해당 위치에 코드가 펼쳐진다.
- 짧은 코드를 반복해서 쓰기 편하지만 호출 횟수만큼 코드 크기가 늘 수 있다.

mPutchar MACRO ch:REQ
    push eax
    mov al,ch
    call WriteChar
    pop eax
ENDM

mPutchar 'A'

- REQ : 필수 인자
- LOCAL : 매크로가 여러 번 펼쳐져도 내부 레이블이 중복되지 않게 함
- ECHO : 어셈블하는 도중 메시지 표시
- EXITM : 매크로 확장 종료

5. 조건부 어셈블
- IF / ELSE / ENDIF : 어셈블할 때 상수식을 판단한다.
- .IF / .ELSE / .ENDIF : 프로그램 실행 중 조건 처리에 사용한다.
- IFB : 매크로 인자가 비어 있는지 검사
- IFIDN / IFIDNI : 텍스트 비교(각각 대소문자 구분 / 무시)
- IFDEF / IFNDEF : 심볼이 정의되었는지 검사
- LT, LE, EQ, NE, GE, GT : 상수식 비교 연산자

6. 매크로 특수 연산자
- & : 인자 이름을 문자열 등에 결합하여 치환
- <> : 쉼표를 포함한 문구 등을 하나의 인자로 취급
- ! : 특수문자를 일반 문자로 취급
- % : 텍스트 매크로 또는 상수식의 결과를 펼침

7. 반복 생성 지시어
- WHILE / ENDM : 상수 조건이 참인 동안 반복 생성
- REPEAT / ENDM : 지정한 횟수만큼 반복 생성
- FOR / ENDM : 인자 목록을 순회
- FORC / ENDM : 문자열의 문자별 반복
- 위 지시어는 실행 중 반복문이 아니라 어셈블 시 코드를 생성한다.
